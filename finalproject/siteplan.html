MovieQueue

W05 Project Site Plan

Site Name

I chose the name MovieQueue because it is short and memorable. It advertises the core function of the website, allowing users to line up and organize their viewing choices in a single centralized location.

Site Purpose

Finding the right movie can be difficult when I have to search several streaming platforms to find exactly what I want. Centralizing movies in one location will help me and other users know exactly where to go to find what we are looking for. The site will allow users to peruse options by genre, read descriptions, check ratings, and watch YouTube trailers all in one place.

Scenarios

  • How can I filter movie options by specific genres to find highly rated titles quickly?
  • Where can I view movie details and trailers in a single centralized location without opening multiple applications?

Color Schema Use in Document

I have designed the technical site plan document to actively utilize the selected color schema within its style parameters. The background utilizes Deep Charcoal, the headings feature Crimson Red, and the main paragraph text uses Pure White.

Typography Named and Used

Primary Font: Roboto

I selected Roboto because it offers clean and modern geometry that reads exceptionally well on both mobile and wider desktop screens. I will apply it globally to the body element of the site plan document and the final website.

Wireframe Configurations

Mobile View

For the mobile view, I plan to use a single column vertical layout. A navigation header will sit at the top of the screen. Below the header, movie poster cards will stack vertically, allowing the user to scroll down through the options.

Desktop View

For the desktop view, I plan to use a responsive grid layout. A horizontal navigation bar will span the top of the screen. Below the navigation, the movie poster cards will be arranged in a flexible grid, displaying multiple titles per row to utilize the wider screen real estate efficiently.

I will construct the final deliverable using strictly valid HTML and CSS. I will ensure the document includes an accurate structure, a descriptive title tag, and passes industry standard validation checks without any markup errors.
